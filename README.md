# 5b Rewind
This is designed to be a tool for a game, **BFDIA 5b**, developed by Cary Huang in 2013. Since November 2018, when Meester Tweester performed the first speedrun of the game, it has cultivated a speedrunning community, whose records are what this tool catalogs.\
When the user picks a date via the slider, the canvas will display the Personal Records at that date for every player, and show the leaderboard at that date.

## Methodology
In *data.js*, the array FiveBerData stores the data of every runner's historical PRs and the dates that they were set.\
Next, in *script.js*, this array is processed to show the "current" PRs of each runner, according to the date chosen on the slider.
Once the PRs of everybody are determined, they are sorted and displayed.
